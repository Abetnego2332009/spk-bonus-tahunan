# 📊 Sistem Pendukung Keputusan Bonus Tahunan Karyawan

Sistem Pendukung Keputusan (SPK) Bonus Tahunan merupakan aplikasi berbasis web yang dikembangkan untuk membantu proses penilaian kinerja karyawan dalam menentukan penerima bonus tahunan menggunakan metode **Simple Additive Weighting (SAW)**.

Aplikasi ini mengelola data karyawan, kriteria penilaian, proses evaluasi, hingga perhitungan nilai akhir sebagai dasar pengambilan keputusan.

## ✨ Fitur Utama

### 1. Dashboard
- Menampilkan ringkasan informasi sistem.
- Informasi data karyawan dan penilaian.

### 2. Manajemen Data
- Pengelolaan data karyawan.
- Pengelolaan kriteria dan subkriteria.
- Pengaturan periode penilaian.
- Pengelolaan data pengguna.

### 3. Penilaian Kinerja
- Penilaian berdasarkan SOP.
- Penilaian berdasarkan pencapaian target.
- Penilaian berdasarkan hasil audit.
- Pengelolaan daftar penilaian karyawan.

### 4. Perhitungan Metode SAW
Sistem menggunakan metode Simple Additive Weighting (SAW) dengan pembobotan sebagai berikut:

| Kriteria | Bobot |
|---|---:|
| SOP | 30% |
| Target | 30% |
| Audit | 40% |
| **Total** | **100%** |

Hasil perhitungan digunakan untuk menghasilkan nilai akhir dan menentukan peringkat karyawan berdasarkan hasil penilaian.

## 🛠️ Teknologi

## 🎯 Tujuan Pengembangan

Membantu proses evaluasi kinerja karyawan agar lebih terstruktur, mempermudah pengolahan data penilaian, serta mendukung pengambilan keputusan dalam menentukan penerima bonus tahunan secara sistematis.
